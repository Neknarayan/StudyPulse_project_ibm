## What it does
StudyPulse helps teachers and mentors find students who are likely to fail *before* exams, and tells them **why** each student was flagged and what support to offer.

1. Loads student records (attendance, previous grade, study hours, absences, past failures, assignment completion, sleep, parental support, internet access).
2. Trains a classifier to predict the **at-risk:* outcome.
3. Scores every student, grouping them into High / Medium / Low risk.
4. Explains each prediction (top factors raising that student's risk) and suggests a support action.
5. Offers a what-if **Risk predictor** form.

## Tech stack
Python, Pandas, NumPy, scikit-learn (Logistic Regression + Random Forest), Matplotlib, Flask, HTML/CSS.

## Project structure
```
app.py                 Flask web app (dashboard, dataset, EDA, model, student, predictor)
requirements.txt

docs/                  Concept Note, presentation, screenshots PDF

```

## Run it
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate     Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m src.data_gen      # (optional) regenerate data
python -m src.train         # trains model, writes metrics + charts
python app.py               # open http://127.0.0.1:5000
```

## Data note (please read)
`data/students.csv` is **synthetic**, generated by `src/data_gen.py`, so the project runs without downloads. Metrics shown in the app come from this synthetic data and demonstrate the pipeline only - they are **not** results on real students.
To use real data, supply a CSV with the same columns (see `FEATURES` in `src/data_gen.py` plus `student_id` and `at_risk`) and re-run `python -m src.train`.

## Responsible use
Predictions are decision *support* for teachers, not automated decisions. Student data is sensitive: use anonymised IDs, restrict access, and review flagged students with a human before acting.

## Limitations & future scope
Synthetic data; simple models; rule-based advice. Next: validate on real anonymised data, fairness checks across groups, weekly attendance trends, teacher feedback loop, cloud deployment.
